# Landsat 8 turntable frames

71 WebP stills, `frame_0001.webp` … `frame_0071.webp`, 960×540, used by
`/showcase/groundtrack` (src/showcase/groundtrack/), the recipe on
`/examples/scroll-frames` (src/recipes/scroll-frames/) and its card preview.

Landsat 8 (LDCM) model animation: NASA/Goddard Space Flight Center Conceptual
Image Lab. Public domain (created by NASA).

- https://svs.gsfc.nasa.gov/10812
- https://commons.wikimedia.org/wiki/File:LDCM_spacecraft_rotating.webm
